PANDUAN PENAMBAHAN FOTO PRESTASI
=================================

Untuk mengganti atau menambahkan foto dokumentasi untuk event ini:
1. Masukkan foto utama Anda ke dalam folder ini dengan nama: cover.jpg
   (Format yang didukung: .jpg, .jpeg, .png, .webp).
2. Jika menggunakan nama file berbeda (contoh: foto-utama.png), Anda cukup memperbarui jalur file di `lib/data.ts`.
3. Foto otomatis akan tampil di landing page pada bagian Galeri Prestasi dan modal detail.
